VaxLink Chrome Extension

Parse GS1 vaccine barcodes and auto-fill CHR fields using NVC-backed terminology and lot metadata.

Open Web Explorer Install Steps

What It Extracts

AI 01 (GTIN), 10 (Lot), 17 (Expiry), 21 (Serial), plus fallback text labels.

What It Fills

Trade name, manufacturer, route, dose, strength, DIN/drug code, lot, and expiry fields.

NVC Sync Model

Uses the NVC bundle endpoint with periodic checks and keeps a last-known-good fallback bundle.

Install (Developer Mode)

  1. Open chrome://extensions.
  2. Enable Developer mode.
  3. Click Load unpacked.
  4. Select VaxLink/VaccineScannerExtension.

After install, open your CHR page, click the extension, scan/paste a barcode, then use Parse and Auto-fill.

Permissions Summary

  1. activeTab, scripting: inject/execute on the current page for autofill.
  2. Supported Panorama/InputHealth site access: run hands-free scan and autofill only on supported chart pages.
  3. storage, alarms: persist data and run periodic NVC update checks.
  4. https://nvc-cnv.canada.ca/*: refresh National Vaccine Catalogue reference data.
