VaxLink Native Scanner Agent

The native scanner agent captures serial/USB CDC scanner input outside the browser and passes confirmed scan events to VaxLink. It does not inject keystrokes into Panorama or other EMR pages.

Windows User Install

  1. Build or obtain vaxlink-scanner-agent.exe.
  2. Run install-user.ps1 with this extension's Chrome or Edge extension ID.
  3. Configure the scanner as USB CDC / virtual COM, not keyboard wedge.
  4. Set VAXLINK_SCANNER_PORT for the user session, for example COM4.
cargo build --release
.\install\windows\install-user.ps1 -ExtensionId "<extension-id>" -RegisterEdge

Runtime Limits

The user-session agent can continue while the workstation is locked if the user session remains active. It does not capture before login, after full logout, during sleep or hibernate, or after shutdown. Those cases require a future admin-installed service.
