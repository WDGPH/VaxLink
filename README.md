# VaxLink

[![CI](https://github.com/WDGPH/VaxLink/actions/workflows/extension-ci.yml/badge.svg)](https://github.com/WDGPH/VaxLink/actions/workflows/extension-ci.yml)
[![Docs](https://img.shields.io/badge/docs-PHIZ-blue)](https://docs.phiz.ca/vaxlink/)
[![Ask DeepWiki](https://deepwiki.com/badge.svg)](https://deepwiki.com/WDGPH/VaxLink)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

VaxLink is a Chrome extension that helps clinic staff record vaccinations in
Panorama. Scan the barcode on a vial or carton and VaxLink looks up the vaccine
in the National Vaccine Catalogue. It can fill in the vaccine and lot on an open
immunization form. You review the details and save the record in Panorama.

Use Inventory to track vaccine lots and expiry dates and download a list you
can open in a spreadsheet.

VaxLink was built by Wellington-Dufferin-Guelph Public Health.
